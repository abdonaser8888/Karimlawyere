# مكتب الأستاذ كريم هشام جميل | المحامي بالاستئناف العالي ومجلس الدولة

الموقع الإلكتروني الرسمي لمكتب الأستاذ كريم هشام جميل للمحاماة والاستشارات القانونية.
تم التطوير والتصميم بواسطة VoroCom.

## كيفية التشغيل محلياً

لتشغيل الموقع على جهازك:

```bash
python server.py
```

ثم افتح المتصفح على:
`http://localhost:8080/`
